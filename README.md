# FollowRoom

**Dynamic client follow-up rooms for relationship-driven sales.**

Upload meeting transcripts or forward selected WhatsApp messages. FollowRoom turns them into a living, client-specific relationship workspace — internal memory the operator owns, plus a polished client-facing room the operator approves before publishing.

The WhatsApp endpoint is a **silent forwarding inbox**, not a conversational bot. All clarification, correction, editing, approval, and publishing happen in the Operator Dashboard.
